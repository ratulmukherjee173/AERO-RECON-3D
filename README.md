# AERO RECON-3D

Generate georeferenced, metrically accurate 3D models from single-pass UAV drone video using AI-powered computer vision and spatial data fusion.

## Launch Instructions

AERO RECON-3D is built as a modern Vite React application. For security and architectural reasons, opening `index.html` directly via `file:///` is intentionally not supported. The application must be served over HTTP.

### ONE-CLICK DEMO (Windows)
Double-click:
**`START_AERO_RECON.bat`**

This launcher will automatically build the project if necessary and start a local web server, opening the production preview.

### LOCAL DEVELOPMENT
To run the hot-reloading development server:
```bash
npm run dev
```
opens: `http://localhost:5173`

### LOCAL PRODUCTION PREVIEW
To build and preview the optimized production frontend:
```bash
npm run build
python -m http.server 4173 --directory dist
```
opens: `http://localhost:4173`

---

## Important Note on Launching
- The root `index.html` is a Vite source entry point, not a standalone web page.
- The `dist/index.html` is a production build artifact generated by Vite.
- The production build should be served over an HTTP web server.
- Direct `file:///` opening (double-clicking the HTML files directly) is intentionally not the supported runtime.
- Always use `START_AERO_RECON.bat` as the convenient double-click launcher for local testing.

---

## Architecture

- **Frontend:** React, Vite, Tailwind CSS, Three.js
- **Backend:** FastAPI, SQLite
- **Pipeline:** MiDaS, Open3D Poisson surface reconstruction, PyTorch
